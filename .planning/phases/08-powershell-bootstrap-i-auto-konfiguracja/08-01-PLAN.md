# Phase 8 - Plan 01: PowerShell bootstrap script (setup.ps1)

## Objective

Create a single `setup.ps1` PowerShell script that, after `git clone`, downloads and configures all dependencies needed for InfoExe to run: ILSpy, .NET SDK verification, NuGet package restore, and SQLite database initialization. The script must be idempotent (safe to run multiple times).

## Requirements Covered

- SETUP-01: Download and install ILSpy (ilspycmd) as global dotnet tool
- SETUP-02: Verify .NET SDK 10.0 presence, install via winget if missing
- SETUP-03: Execute `dotnet restore src/InfoExe.sln`
- SETUP-04: Create `%LOCALAPPDATA%/InfoExe/` directory and initialize SQLite database

## Implementation

### 1. Script Structure

```
setup.ps1
├── Header (banner, admin check)
├── Step 1: Check/install .NET SDK 10.0
├── Step 2: Install ILSpy as dotnet tool
├── Step 3: dotnet restore
├── Step 4: Initialize SQLite database
└── Summary (success/failure report)
```

### 2. Script Content

```powershell
# setup.ps1 — InfoExe bootstrap
# Uruchom: .\setup.ps1

$ErrorActionPreference = "Stop"
Write-Host "=== InfoExe Setup ===" -ForegroundColor Cyan

# Step 1: .NET SDK 10.0
Write-Host "`n[1/4] .NET SDK 10.0..." -ForegroundColor Yellow
$dotnetVersion = dotnet --version 2>$null
if ($LASTEXITCODE -ne 0 -or -not $dotnetVersion.StartsWith("10.")) {
    Write-Host "Installing .NET SDK 10.0 via winget..."
    winget install Microsoft.DotNet.SDK.10 --accept-source-agreements --accept-package-agreements
    refreshenv
    $dotnetVersion = dotnet --version
    Write-Host ".NET SDK $dotnetVersion installed" -ForegroundColor Green
} else {
    Write-Host ".NET SDK $dotnetVersion already present" -ForegroundColor Green
}

# Step 2: ILSpy
Write-Host "`n[2/4] ILSpy (ilspycmd)..." -ForegroundColor Yellow
$ilspyInstalled = dotnet tool list --global 2>$null | Select-String "ilspycmd"
if (-not $ilspyInstalled) {
    dotnet tool install --global ilspycmd --version 8.2.0.7535
    Write-Host "ILSpy installed" -ForegroundColor Green
} else {
    Write-Host "ILSpy already installed" -ForegroundColor Green
}

# Step 3: NuGet restore
Write-Host "`n[3/4] NuGet restore..." -ForegroundColor Yellow
Push-Location $PSScriptRoot
dotnet restore src/InfoExe.sln
Write-Host "NuGet packages restored" -ForegroundColor Green

# Step 4: SQLite database
Write-Host "`n[4/4] SQLite database..." -ForegroundColor Yellow
$dataDir = Join-Path $env:LOCALAPPDATA "InfoExe"
New-Item -ItemType Directory -Force -Path $dataDir | Out-Null

# Initialize database by running the app once with --db flag
dotnet run --project src/InfoExeApp -- --db "$dataDir/infoexe.db" help > $null 2>&1
Pop-Location
Write-Host "Database initialized at $dataDir/infoexe.db" -ForegroundColor Green

Write-Host "`n=== Setup complete ===" -ForegroundColor Cyan
Write-Host "Run: dotnet run --project src/InfoExeGui" -ForegroundColor White
```

### 3. Idempotency Guarantees

- .NET SDK check: verifies version starts with "10." before skipping install
- ILSpy: checks `dotnet tool list --global` before installing
- dotnet restore: always safe to re-run (no-op if up to date)
- SQLite: `New-Item -Force` is idempotent; running help command initializes tables via `CREATE TABLE IF NOT EXISTS`

### 4. Error Handling

- `$ErrorActionPreference = "Stop"` — script stops on first error
- Each step reports success/failure clearly
- `winget` handles download failures with built-in retry
- `dotnet restore` fails fast if network unavailable

### 5. Testing Plan
