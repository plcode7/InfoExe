# Milestone v1.1: Samodzielna aplikacja

**Status:** ✅ SHIPPED 2026-05-16
**Phases:** 8-9
**Total Plans:** 2

## Overview

Milestone v1.1 transforms InfoExe from a CLI-dependent application into a standalone GUI with auto-configuration. Users can now run `setup.ps1` to automatically install all dependencies (.NET SDK, ILSpy, NuGet packages) and initialize the database. The GUI now embeds scan logic directly (no subprocess dependency), shows real-time progress, and auto-detects required tools at startup.

## Phases

**Goal:** Stworzyć skrypt `setup.ps1`, który po jednorazowym uruchomieniu pobiera i konfiguruje wszystkie zależności (ILSpy, .NET SDK, NuGet, SQLite), tak aby aplikacja była gotowa do pracy bez manualnej konfiguracji.

**Requirements:** SETUP-01, SETUP-02, SETUP-03, SETUP-04

**Success criteria:**
1. `setup.ps1` pobiera ILSpy jako `dotnet tool` i weryfikuje dostępność `ilspycmd`

## Milestone Summary

**Decimal Phases:**

None

**Key Decisions:**

- Decision: Embed scan logic in GUI instead of calling CLI subprocess (Rationale: Better UX, no external dependency, real-time progress)
- Decision: Use PowerShell for bootstrap script (Rationale: Native to Windows, easy to run, idempotent design)
- Decision: Keep report generation using CLI subprocess (Rationale: Analyze command not yet embedded, future work)

**Issues Resolved:**

- GUI required manual CLI path configuration — resolved with embedded scan logic
- No progress indication during long scans — resolved with determinate progress bar and live output
- Tool availability unclear — resolved with startup tool check and status indicators

**Issues Deferred:**

- Analyze command embedding (report generation still uses CLI subprocess)
- Full GUI independence from InfoExeApp.exe

**Technical Debt Incurred:**

- Report generation still depends on InfoExeApp.exe (analyze command not embedded in GUI)
- REQUIREMENTS.md checkboxes not updated during implementation (automation gap)
