<objective>
Create the unified solution file `src/InfoExe.sln` and upgrade Avalonia packages from
11.2.0 to 11.3.15 in `InfoExeGui.csproj`. Suppress the NU1903 transitive advisory
warning if it persists after the upgrade.

one-command builds, IDE solution-level actions, and CI parity. The Avalonia upgrade
moves onto the current stable 11.3.x track and may resolve the NU1903 advisory
(`Tmds.DBus.Protocol` 0.20.0) that surfaces in the build output.

- `src/InfoExe.sln` — new file, references both csproj projects
- `src/InfoExeGui/InfoExeGui.csproj` — four Avalonia* packages bumped to 11.3.15,
  optional `<NoWarn>NU1903</NoWarn>` if warning survives the upgrade

<task type="auto">
  <name>Task 2: Upgrade Avalonia to 11.3.15 and suppress NU1903 if needed</name>
  <files>src/InfoExeGui/InfoExeGui.csproj</files>
  <action>
    Edit `src/InfoExeGui/InfoExeGui.csproj`. Change all four Avalonia package
    versions from `11.2.0` to `11.3.15`:

    ```xml
    <PackageReference Include="Avalonia"                Version="11.3.15" />
    <PackageReference Include="Avalonia.Desktop"        Version="11.3.15" />
    <PackageReference Include="Avalonia.Themes.Fluent"  Version="11.3.15" />
    <PackageReference Include="Avalonia.Fonts.Inter"    Version="11.3.15" />
    ```

    **Do NOT** change `AvaloniaUseCompiledBindingsByDefault` — it must remain
    `true` or AXAML compiled bindings will break.

    **Do NOT** upgrade to 12.x** — Avalonia 12.0.x is a separate major series
    with breaking changes. Stay on 11.3.15.

    After editing, run a restore + build to pull the new packages:
    ```powershell
    dotnet restore src/InfoExeGui/InfoExeGui.csproj
    dotnet build src/InfoExeGui/InfoExeGui.csproj 2>&1 | Tee-Object -Variable buildOutput
    $buildOutput | Out-String
    ```

    Check the build output for the NU1903 warning:
    ```powershell
    $hasWarning = $buildOutput | Select-String "NU1903"
    ```

    **If NU1903 is still present after the upgrade:** add
    `<NoWarn>NU1903</NoWarn>` inside the existing `<PropertyGroup>` in
    `InfoExeGui.csproj`. This silences the transitive advisory for
    `Tmds.DBus.Protocol` which is the Linux D-Bus backend — it is never
    activated on Windows at runtime (the Win32 backend loads instead).

    **If NU1903 is gone after the upgrade:** do not add NoWarn — the newer
    Avalonia transitive pulled a fixed version.

    Final check — run the full solution build:
    ```powershell
    dotnet build src/InfoExe.sln
    ```
    Must exit 0 with no errors and no NU1903 warning.
  </action>
  <verify>
    <automated>dotnet build src/InfoExeGui/InfoExeGui.csproj 2>&amp;1 | Select-String -Pattern "NU1903|error CS|Build succeeded"</automated>
  </verify>
  <done>
    `InfoExeGui.csproj` has all four Avalonia packages at version `11.3.15`.
    `dotnet build src/InfoExeGui/InfoExeGui.csproj` exits 0 with no errors and
    no NU1903 advisory warning in output. `AvaloniaUseCompiledBindingsByDefault`
    is still `true`.
  </done>
</task>
