# Phase 7 - Plan 03: Extend GUI with report preview, generation, and result actions

## Objective

Extend the InfoExeGui Avalonia application to provide a polished report generation experience: scan selection, format configuration, live preview of results, and post-generation actions (open report, open in browser, open in explorer).

## Requirements Covered
- ANALYZE-05: GUI form to select scan, configure report options, and preview/open generated reports

## Implementation

### 1. Fix Critical Bug: LoadScans() never called

The `LoadScans()` method exists but is never invoked. Must be called:
- On window `Loaded` event
- After a scan completes (so new scans appear)

### 2. GUI Enhancements

**Report Generation Panel** (already exists in MainWindow.axaml):
- Scan ID dropdown (populated from DB) - FIX loading
- Format radio buttons (MD/HTML) - EXISTS
- Output path with browse - EXISTS
- Generate Report button - EXISTS

**NEW: Post-Generation Actions**
Add buttons after report generation:
- "Open Report" — opens the generated file with default application
- "Open in Explorer" — opens the containing folder
- "Open in Browser" — opens HTML report in default browser

### 3. Live Preview Enhancement

After report generation:
- Show report file path
- Show file size
- Show a preview of the report content (first 50 lines)

### 4. Integration with Scan Flow

After a scan completes successfully:
- Automatically refresh the scan list
- Optionally auto-select the newly completed scan

### 5. Error Handling

- Graceful handling when no scans exist
- Clear error messages when report generation fails
- Loading states during generation
