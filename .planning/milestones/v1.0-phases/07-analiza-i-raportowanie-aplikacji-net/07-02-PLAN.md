# Phase 7 - Plan 02: Implement enhanced `analyze` command with MD/HTML generation

## Objective

Implement the enhanced `analyze` command that generates comprehensive MD and HTML reports including technology stack detection, dependency graphs, license analysis, build process analysis, and code quality metrics.

## Requirements Covered
- ANALYZE-01 through ANALYZE-04
- ANALYZE-02: Assembly metadata with dependencies
- ANALYZE-03: Dependency graph, encoding detection
- ANALYZE-04: MD and HTML output

## Implementation

### 1. Enhanced `AnalysisReportBuilder.BuildReport()`

- **Technology Stack Detection**: Parse `target_framework` from assembly_metadata to classify as .NET Framework, .NET Core, .NET 5+, Native, or Unknown
- **Dependency Extraction**: Read assembly references using `System.Reflection.Assembly.LoadFrom` to get `GetReferencedAssemblies()`
- **License Detection**: Scan root_path for LICENSE, LICENSE.txt, LICENSE.md files; extract license type from content
- **Build Process Analysis**: Scan root_path for .sln, .csproj, .props, .targets, Dockerfile, .github/workflows/*.yml, Jenkinsfile, azure-pipelines.yml
- **NuGet Package Detection**: Parse decompiled .csproj files for PackageReference elements
- **Code Metrics**: Count decompiled .cs files, total lines of code from decompiled artifacts
- **Encoding Detection**: Detect encoding from decompiled source files (not binary DLLs)

### 2. Enhanced `MarkdownReportFormatter.Format()`

New sections:
- Executive Summary (technology stack overview)
- Technology Stack (table of detected frameworks)
- Assemblies (enhanced with dependencies, licenses)
- Dependency Graph (mermaid-style or table)
- Licenses Detected
- Build Process (build files found)
- Code Metrics

### 3. Enhanced `HtmlReportFormatter.Format()`

Same sections as MD, with:
- Better styling (matching Avalonia GUI aesthetic)
- Responsive layout
- Dependency graph as HTML table
- License badges

### 4. CLI Usage

```bash
infoexeapp analyze --id <scanId> --format md [--output <path>]
infoexeapp analyze --id <scanId> --format html [--output <path>]
```
